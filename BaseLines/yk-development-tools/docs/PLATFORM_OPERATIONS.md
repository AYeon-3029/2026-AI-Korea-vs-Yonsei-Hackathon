# 대회 서버와 로컬 개발 도구

이 묶음의 게임·예제 소스는 게임 커밋 88a77d888a1562e52ca2b21b2363d52bb8ce307c에서 가져왔다.
docs/rulebook.md는 대회 웹사이트와 같은 공개 규칙서다. 플랫폼 운영 정책은 웹사이트 규칙·자료의 안내를 따른다.

- 게임은 160턴, 일반 턴 300ms, 첫 턴은 기동·초기화·첫 응답까지 합해 3000ms다.
- 양측 오류는 무승부로 각각 0.5점이며 정상 경기의 동점 판정은 게임 엔진을 따른다.
- 여러 Python 모듈과 C++ 소스·헤더, 서버에서 제공하는 NumPy를 사용할 수 있다.
- 마감 시각까지 업로드를 끝내고 선택한 코드만 그 회차에 사용한다. 검사 중인 코드를 선택할 수도 있지만,
  해당 코드가 검사에 실패하면 다른 코드로 자동 대체하지 않는다. 빌드 검사는 마감 후에도 이어질 수 있다.
- 연습은 하·중·상 중 하나를 골라 공개 시드 0~9에서 소속 진영을 유지한 10경기를 치른다.
  중 난도 6승 이상이면 수료 기준을 충족하며 무승부는 승리에 포함하지 않는다.
- 제출·연습 작업은 각각 진행 중인 작업이 끝난 뒤 다시 요청한다. 세부 일정은 웹사이트를 확인한다.
- 문의는 대회 웹사이트의 채널톡을 사용한다.

로컬 도구는 전략 개발용이며, 서버의 격리·메모리·CPU 제한이나 전체 경기 인프라 제한을 재현하지 않는다.
로컬 출력 검사에서는 한도 초과를 경고로 표시하지만, 대회 서버에서는 출력 제한 초과 시 몰수 처리한다.
서버에서 전체 경기 인프라 시간 제한을 넘으면 참가자 패배 대신 같은 조건으로 재시도하며 운영진에게 알린다.
로컬에서 통과하더라도 서버에서 사용하는 CPU·메모리 환경에 따라 성능은 달라질 수 있다.

플랫폼 배포 수정: 공개 규칙서와 이 설명을 교체하고 _support.py는 문서 제목 대신 limits.json에서
실행 제한을 읽는다. 게임 엔진·맵 생성·전략 소스와 러너의 경기 실행 로직은 원본을 유지한다.
로컬에서 사용할 수 없던 구형 운영용 자동 평가 명령은 제거했다. 내부 기준 봇·서버 운영 도구는
포함하지 않는다. 수정·제외 파일은 docs/platform-sdk-provenance.json에 기록되어 있다.
