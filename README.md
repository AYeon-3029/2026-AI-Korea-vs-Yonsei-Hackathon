# 🚩 2026 연고전 AI 해커톤 — 깃발 대항전 봇

**팀 어잌후** (고려대학교) · 김정훈(팀장, 컴퓨터학과) · 이다슬(컴퓨터학과) · 정성윤(전자및정보공학과)

160턴 동안 캠퍼스 건물을 점령해 점수를 겨루는 깃발 대항전에서 사용한 규칙 기반 봇입니다.
최종 제출본은 **봇 v36**(서버 제출 v38, `submissions/submission-Junghoon-v36.zip`)입니다.

## 전략 한눈에 보기

- **경제 먼저, 병력은 최대로** — 초반에 학생회관·공학관·보급소를 확보하고, 깃발병 생산 외 자원은 모두 전투병에 씁니다.
- **넓게 펼치고 약한 곳을 친다** — 전투병은 아군이 적은 칸으로 퍼져 통제 면적을 넓히고, 수비가 얇은 적 경제 건물부터 기습합니다.
- **깃발병은 살아남는다** — 실제 리더보드 83경기로 학습한 위험 모델로 위험한 칸을 피하고, 갇히면 전투병이 탈출로를 엽니다.
- **막판엔 점수만 본다** — 151턴부터는 160턴 점수 판정에 맞춰 목표를 고릅니다.

자세한 설명은 [보고서](submissions/)에 있습니다.

## 폴더 구조

```
├── Model/               최종 봇 v36 (제출 ZIP과 동일)
├── submissions/         최종 제출 ZIP, 보고서(docx·pdf)
├── Real Match Replay/   대회 공식 리더보드 회차별 경기 리플레이와 전체 팀 순위 기록
├── tools/               대전·튜닝·분석 도구
│   ├── arena.py           두 봇을 여러 시드·양 진영으로 대전시켜 승률 집계
│   ├── tune_optuna.py     Optuna 파라미터 탐색
│   ├── macro/             리더보드 경기 분석, 상위 팀 흉내 봇, 실제 경기 상태 분기 평가
│   ├── lb_*.py, real_*.py 리더보드 리플레이 분석 스크립트
│   ├── make_zip.py        서버 제출용 ZIP 생성
│   └── viewer.html        리플레이를 턴별로 보는 브라우저 뷰어
├── BaseLines/           대회 제공 스타터 킷과 게임 엔진
├── Rules/               대회 규칙, 공지, 보고서 양식
├── VERSIONS.md          버전 발전 목록
└── DEVLOG.md            개발 기록
```

## 실행해 보기

WSL(Ubuntu) 환경의 프로젝트 루트에서 실행합니다.

```bash
# 대회 제공 예제 봇(lv1 · lv2 · main)과 시드 0~29, 양 진영으로 대전
python3 tools/arena.py --a "python3 Model/main.py" --b lv2 --seeds 0-29

# 코드 수정 없이 파라미터만 바꿔 실험
python3 tools/arena.py --a "BOT_PARAMS='{\"use_tele\":false}' python3 Model/main.py" --b lv2

# 제출용 ZIP 만들기 → submissions/submission-Junghoon-<버전>.zip
python3 tools/make_zip.py <버전>
```

리플레이는 `tools/viewer.html`을 브라우저로 열고 JSON 파일을 불러오면 볼 수 있습니다.
